# 人才发展管理高保真原型

> 公开展示版本｜用于产品方案演示、交互评审与交流参考。

## 项目简介

这是一套面向人才发展与员工发展管理场景的高保真交互原型。

当前版本以单文件 HTML 形式交付，用于展示人才信息管理、阶段评估、培养信息、人才分层以及管理简报等核心业务流程。

## 在线预览

启用 GitHub Pages 后，可通过以下地址访问：

https://zoeyan-aihr.github.io/talent-development-management-system/cadre-pro-talent-development/

## 主要页面与功能

- 发展管理工作台
- 员工列表与员工档案
- 阶段性评估记录与评估表单
- 委培 / 培养信息管理
- 人才分层矩阵
- 管理简报生成、预览与导出
- 系统权限管理

## 使用方式

- 直接使用浏览器打开 `index.html` 即可预览。
- 如需通过本地静态服务器运行，可在该项目文件夹执行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。
